# Лицензии и атрибуция RusCraft

Итоговая таблица (обновляется вместе с составом паков):

| Компонент | Лицензия | Что требует от нас |
|---|---|---|
| Luanti (движок) | LGPL-2.1-or-later | открыть исходники наших изменений/сборки, сохранить копию LGPL, уведомление об использовании |
| luanti-wasm (харнесс) | MIT | сохранить копию MIT + копирайт |
| webshims, lwproxy | MIT | тоже |
| Minetest Game (если выбрана) | код LGPL 2.1 / MIT-файлы, медиа CC BY-SA 3.0 (см. license.txt репо) | исходники пака открыты, атрибуция медиа |
| VoxeLibre (если выбрана) | GPL-3.0 (+ медиа CC BY-SA) | весь дистрибутив под GPL-совместимыми условиями, исходники открыты |
| Русские переводы | те же лицензии, авторы — переводчики Weblate | атрибуция в credit-секции |

Название RusCraft: не аффилировано с Luanti Foundation и с Mojang/Minecraft.
В UI обязателен экран «Об игре»: «Построено на Luanti», ссылки на репо движка и наш.

Оба кандидата игровых паков открытые → выбор любой не ломает открытость RusCraft.
Осторожно: «похожесть на Minecraft» обеспечивается только открытым клоном-паком;
копировать ассеты/названия Minecraft нельзя.
