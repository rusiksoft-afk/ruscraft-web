# CONSTRAINTS.md — стандарты качества RusCraft

Пороги не понижаются без явного решения человека. Любое понижение — запись в журнал
`docs/PLAN.md` с причиной.

## 1. Язык и аутентичность
- Оболочка лаунчера: **100 % русский** (все видимые строки). Игровой UI Luanti:
  ru-перевод апстрима; критические экраны (новое меню, создание мира, настройки) —
  без английских строк. [статичная проверка скриншотами на S3/S5]
- Визуально и по управлению — максимально близко к оригинальному Luanti
  (те же formspec-экраны, та же палитра; бренд только в оболочке).

## 2. «Полностью на WEB»
- Первый запуск и весь геймплей — в браузере, без плагинов/загрузчиков/установок.
- Обязательная поддержка: Chromium/Edge и Firefox последних 2 мажорных версий;
  Safari — по результатам S8 (иначе явно в README).
- `crossOriginIsolated === true` на стенде; никаких сторонних CDN в HTML
  (ломает COEP) — шрифты/иконки только свои.

## 3. Лицензионная чистота
- Никаких проприетарных ассетов (в т.ч. «майнкрафтовых» текстур/звуков/названий).
- Атрибуция Luanti + luanti-wasm + авторов игровых паков — в UI «Об игре» и
  `docs/LICENSES.md`. Собственные изменения открыты (LGPL-обязательство).

## 4. Производительность (дефолтный профиль «desktop-normal»)
- Первый визит (без кэша): wasm + base.pack + игровой пак ≤ 60 МБ (wasm.gz).
- Время до первого меню ≤ 60 с на проводном соединении (замер в S2).
- FPS ≥ 30 в мире с viewing_range=100 на средних ПК (замер F5 в S2/S4).
- Память вкладки ≤ 3 ГБ.

## 5. Надёжность
- Миры игрока не теряются при обновлении версии RusCraft (механика паков апстрима
  это обеспечивает — регресс-тест: мир с S2 играбелен после обновления сборки).
- Сетевой режим: обрыв соединения не портит мир (тест на S6).

## 6. Качество кода
- `node scripts/serve.js --selftest` зелёный (заголовки COOP/COEP/MIME) — CI-гейт.
- Никаких ручных шагов в сборке: всё через CI/скрипты (`docs/BUILD.md`).
- Версии зависимостей пиннятся (`versions.lock`); «latest» в сборке запрещён.
